# Full-Resolution Hero Images

Drop one or more full-resolution camera photographs into this folder (`app/public/hero/`).

### How It Works

- **Multiple Photos Supported:** You can add as many photos as you want (e.g. `ferrari.jpg`, `porsche.jpg`, `monza.jpg`, `01.jpg`, etc.).
- **Animated Sequence:** The home hero rotates through every WebP master every 20 seconds, with previous/next controls and an accessible photo counter.
- **Single Resolution:** Keep only the largest optimized WebP master in this folder. Do not add generated `-1440`, `-2560`, or `-3840` variants.
